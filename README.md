# Masters of Water and Stone

## Supplementary information

This repository provides the data and code required to reproduce the results presented in:

**Moyano Di Carlo, Julián. 2027. Masters of Water and Stone. Exploring the Role of Rock Art Carvers in Nordic Bronze Age Societies. Swedish Rock Art Research Series 11. Oxbow Books.**

## Repository structure

```text
Masters-of-Water-and-Stone/
├── Codebook.pdf
├── data/
│ ├── csv/
│ ├── jpg/
│ └── shp/
├── graphics/
├── notebooks/
├── output/
└── scripts/
└── images/

## Contents
	•	Codebook.pdf: Description of the variables and data included in the repository.
	•	data/csv/: Data tables in CSV format used in the analyses.
	•	data/jpg/: Images with outlines used in the morphometric analyses.
	•	data/shp/: Figures from Aspeberget and panels from Bohuslän in ESRI Shapefile format.
	•	graphics/: Graphics associated with the analyses.
	•	notebooks/: Rendered HTML versions of the analytical notebooks.
	•	output/: R objects and intermediate analytical outputs required by the analyses.
	•	scripts/: Quarto (.qmd) source files containing the analyses.
	•	scripts/images/: Images used by the Quarto documents.

## Reproducibility
The files in this repository are intended to provide the data, code, and intermediate outputs necessary to reproduce the analyses presented in Masters of Water and Stone.
See Codebook.pdf for information about the structure and contents of the datasets.
